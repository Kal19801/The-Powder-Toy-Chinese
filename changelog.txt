v1.1.1 - EM field fixes: 0.5x fullscreen region, EMADJ add/subtract, fast open boundary
- 0.5x region size now means "the simulated space is half", not "half the screen": the
  domain is half the canvas per axis and the renderer magnifies it 2x so the EM field
  still covers the FULL screen (no dead borders). Waves cross the visible canvas twice
  as fast with twice the on-screen wavelength, and the cell count still drops 4x,
  keeping 0.5x the cheap option (设置 -> 电磁场区域大小 -> 0.5x)
- EMADJ add/subtract fixes (the "加法模式无法连续增加" bugs):
  * the conductivity override was silently dropped on every cell that also carries
    magnetization (EMFM/FE/FEPW), so the conductivity of ferromagnetic conductors could
    not be raised at all; conductivity and magnetization are applied independently now
  * magnet direction add/subtract mixed degrees (tool value) with a 0..1 fraction
    (stored direction) and rotated by value/360 degrees per application; all three
    modes operate in degrees now and accumulate exactly once per 0.2s stroke event,
    immune to the brush hitting one EM cell cellSize^2 times per stroke
  * consistent clamp floors between the tool and the field sync (conduct .01..1,
    magnet strength .01..2) so subtracting past the limit cannot get stuck
- Open boundary (开放) performance, previously ~4x the simulation cost of the other
  two modes, now 1.5x while idle and 2.2x while actively absorbing (measured at the
  default 2px cells with the EM self-test benchmark; the EM field is only part of a
  frame, so the FPS gap is smaller still):
  * the absorber band is 64px thick with a 4x stronger graded profile (same optical
    depth, pulse reflectometry re-calibrated: |R|^2 ~ 1e-11 at the default frequency);
    the old 256px band covered 3.3x the visible domain at the default 2px cells
  * a per-frame activity gate skips the two band passes while the band and an 8-cell
    interior guard strip are entirely quiet - numerically exact, and the gate wakes up
    at least a frame before any wave can reach the interface
  * the material sync, boundary-flag sweep, renderer and field-force passes iterate
    the simulated domain / visible window only; the anti-divergence scan skips the
    quiet band (the gate already proved it finite and below the noise floor)
- Fixed a 4px dead column/row at the canvas edge for EM cell sizes that do not divide
  the canvas evenly (cs 8/16 at 1x, cs 4/8/16 at 0.5x): the last cell stretches to the
  edge, so the field always covers the whole canvas
- CI: the two 32-bit Windows jobs (Starcatcher-i686-win-mingw-static,
  x86_old-windows-mingw-static-release) no longer try to install mingw-w64-i686-7zip /
  mingw-w64-i686-jq, which do not exist in the MSYS2 MINGW32 repository; 7z comes from
  the MSYS p7zip package instead and jq was never used
- Debug: the EM self test (EMFIELD_DEBUG builds) gained end-to-end EMADJ stroke tests
  through the real game loop, PML gate state tests and 0.5x zoom mapping tests

v1.1.0 - EM wave II: rewritten current system, EM and real zone categories
- New "电磁场" (EM field) element category with the full EMWave2 painting mode set as elements:
  Perf./Good/Fair Conductor (EMPC/EMEC/EMFC), Current (+/-) (EMJP/EMJN), Ferromagnet (EMFM),
  Diamagnet (EMDM), Dielectric (EMDE), Magnet Down/Up/Left/Right (EMMGD/EMMGU/EMMGL/EMMGR),
  Resonant Medium (EMR) and the EMW wave source
- New unified PROP-like EM adjust tool (EMADJ) with six properties (conductivity / permeability /
  current / dielectric / magnet direction / magnet strength) and three application modes:
  set, add and subtract at 0.2s intervals; replaces the six separate EMAJ*/EMMD tools
- New "真实区" (real zone) category: real proton (RPRO, 1836 electron masses), real electron
  (RELC) and magnetic monopole (RMON) as the current carriers of the rewritten current system
- Real zone materials: iron (FE), titanium (TI), copper (CU), silver (AG), superconductor
  (SCND, quenches above 93K) and pyrolytic graphite (PGRF) plus all six powder forms
  (FEPW/TIPW/CUPW/AGPW/SCPW/PGPW) with field interactions (iron filings line up,
  diamagnetic levitation, Meissner expulsion, Joule heating, melting)
- Rewritten current system on the EMWave2 mechanism: moving real charges deposit current
  along their path (J = q v delta(x)); monopoles inject magnetic current driving dazdt;
  the original TPT current (SPRK/ELEC sources) is no longer used by the field
- Anti-FTL: real particle velocity is strictly clamped to the field propagation speed
  (max group velocity tadd/2 cells per sub-step) and the wave integrates in fixed
  sub-steps of the exact applet timestep, which keeps the CFL bound perm <= 32 satisfied
  and removes the ferromagnet self-excitation divergence
- All modifications to original elements reverted: METL/GLAS/IRON/SPRK/ELEC and friends
  no longer participate in the EM field and keep their vanilla behaviour
- EMCLR now only clears the EM field state and never deletes particles; matter is removed
  with the normal eraser like before
- Fixed erased conductors leaving an invisible radiating current blob behind: induced
  cell currents drop with their conductor and dormant tool overrides are wiped when a
  cell loses its material
- Field simulation resets together with the pressure system: = resets both, clear_sim
  and every save load wipe all EM state (no more cross-save leaks)
- Energy conservation hardening: CFL-proven sub-stepping, bounded current injection,
  wave state safety clamp (never engages, tracked in debug builds)
- Debug blocks kept behind EMFIELD_DEBUG (EMField tracing + EMSelfTest with divergence
  soak tests); compiled out of release builds
